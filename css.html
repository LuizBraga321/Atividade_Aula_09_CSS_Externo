02 • ESTILOS

CSS externo e seletores

Na Aula 09, o destaque é separar aparência e estrutura. Um único arquivo style.css contém as regras que todas as páginas HTML compartilham.

Como conectar o CSS ao HTML?

Dentro do <head> de cada página existe esta linha:

<link rel="stylesheet" href="style.css">

O navegador lê style.css e aplica as regras ao conteúdo. Se mudarmos a cor do cabeçalho no CSS, a alteração aparece em todas as páginas do site.

Três maneiras de selecionar elementos

SELETOR DE TAG

p

Aplica o estilo a todos os parágrafos da página.

p {
  line-height: 1.7;
}
SELETOR DE CLASSE

.cartao

Pode ser reutilizado em diversos elementos.

.cartao {
  padding: 24px;
}
SELETOR DE ID

#conteudo

Representa um identificador único na página.

#conteudo {
  min-width: 0;
}

Class ou ID?

class="cartao"

Usada em vários cartões deste site: estilos que se repetem.

id="menu-principal"

Usado uma única vez em cada página para identificar a navegação.

Teste prático: abra o arquivo style.css, localize .cartao e altere sua borda. Todos os cartões que utilizam essa classe mudarão juntos.
