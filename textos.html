04 • TIPOGRAFIA

Estilização de textos com CSS

Um site precisa ser organizado, mas também fácil de ler. As propriedades de tipografia controlam fontes, tamanhos, cores e espaçamentos.

Textos com estilos diferentes

FONT-FAMILY

Uma fonte clara e legível.

Arial, Helvetica, sans-serif
FONT-WEIGHT

Texto em negrito para destacar informações.

font-weight: 700
FONT-STYLE

Uma observação com estilo itálico.

font-style: italic
LETTER-SPACING

LETRAS ESPAÇADAS

letter-spacing: 3px

Propriedades importantes

Propriedade O que faz Exemplo
font-family Escolhe a fonte. Arial, sans-serif
font-size Define o tamanho. 1.25rem
font-weight Controla o peso. 700
color Define a cor. #193153
text-align Alinha o texto. center
line-height Espaça as linhas. 1.7

Exemplo de CSS para parágrafos

p {
    font-family: Arial, Helvetica, sans-serif;
    font-size: 1rem;
    line-height: 1.7;
    color: #34445b;
}
Perceba: os textos desta página estão estilizados por classes no mesmo arquivo externo usado pelas outras páginas.
