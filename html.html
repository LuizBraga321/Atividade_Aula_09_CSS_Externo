01 • FUNDAMENTOS

HTML: a estrutura da página

HTML é a linguagem de marcação que define o que aparece em um site. O CSS, por sua vez, decide como esses elementos vão ser apresentados.

Uma página bem organizada

Os elementos semânticos ajudam a separar as partes do documento de acordo com a função de cada uma.

<header>

Cabeçalho

Identificação do site ou de uma seção.

<nav>

Navegação

Conjunto de links para outras páginas.

<main>

Conteúdo

Assunto principal de cada página.

Exemplo de estrutura HTML

Este exemplo usa as tags básicas e inclui a conexão com o arquivo CSS externo:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu site</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>Meu cabeçalho</header>
    <nav>Menu de navegação</nav>
    <main>Conteúdo principal</main>
    <footer>Rodapé</footer>
</body>
</html>
Observe no projeto: o cabeçalho, o menu e o rodapé aparecem em todas as páginas; o conteúdo principal muda conforme o link escolhido.
