03 • ORGANIZAÇÃO

DIV, layout e responsividade

O elemento <div> ajuda a agrupar partes da página. Com CSS, esses grupos podem receber tamanho, cor, espaço e posição.

Como este site foi organizado?

Nas telas maiores, o menu aparece ao lado do conteúdo. Nas telas pequenas, ele passa para cima do conteúdo.

O Flexbox posiciona os elementos

Neste projeto, display: flex organiza o menu lateral e o conteúdo. O gap controla os espaços entre os cartões.

.layout {
    display: flex;
}
.grade-cartoes {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

Margin e padding

MARGIN

Espaço do lado de fora

Afasta um elemento dos demais.

margin: 20px;
PADDING

Espaço do lado de dentro

Afasta o conteúdo das bordas do elemento.

padding: 20px;

Ajuste para telas menores

Usamos uma media query para reorganizar o layout no celular:

@media (max-width: 780px) {
    .layout {
        flex-direction: column;
    }
}
Faça o teste: diminua a largura da janela do navegador para observar o menu e os cartões se adaptando automaticamente.
